# 프롬프트 검증 매트릭스

생성일: 2026-09-13 · 엔진: `js/prompt.js`

각 프롬프트는 **같은 얼굴 사진 1장**을 입력 이미지로 넣고 GPT Image-2 편집(Edit)으로 생성한다. 세로(3:4 또는 2:3), quality high. 결과는 `index.html`의 해당 후보 카드에 올려 비교한다.

- 그대로: 옵션(헤어 컬러·피부톤)을 적용해도 얼굴 일관성이 유지되는가. 깨지면 그대로에서는 피부톤·눈 색 옵션을 막는 것을 검토

- 디렉션: 자세·배경을 바꾸지 않고 무드·표정·소품에만 반영되는가
