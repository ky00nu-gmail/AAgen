# AI 모델 만들기 — ver3 (2026-09-17)

blurblur `/make/model/create` 화면 구조를 그대로 옮긴 내부용 정적 웹앱. (원본 화면 캡처 PDF는 저장소에 포함하지 않음) 내 얼굴 사진으로 브랜드 모델 후보를 만들고, 3단계(그대로·약하게·글로우) 비교 이미지에서 하나를 골라 데뷔한다.

## 실행

빌드 없음. `index.html`을 브라우저(Chrome 권장)로 열거나 로컬 서버로 서빙한다.

```bash
python3 -m http.server 8765
```

## ver1 기능

- 내 얼굴 모델 / 랜덤 모델(인간·동물·애니) 탭. 얼굴 사진 업로드 → 사진 설정(원본/크롭 1:1·3:4, 드래그·줌)
- 옵션: 성별, 인종(칩) → 국가(칩), 나이대(칩), 외형 디테일(체형·헤어·컬러·눈·피부톤·메이크업·타투, 셔플), 디렉션, Tips
  - 헤어 스타일은 성별에 따라 목록이 바뀜: 여성 20종 / 남성 19종(자연스러운 숏컷·댄디컷·쉐도우펌·가르마펌·투블럭·콤마헤어·포마드 등, '지정 안 함' 포함). 프롬프트 영문 매핑은 `js/prompt.js`의 `EN.hairM`
- 생성 = 3단계 비교 프롬프트 1장(그대로·약하게·글로우, 정면 증명사진 자세, 라이트그레이 배경). 프롬프트는 버튼 아래 즉시 표시, 복사
- "GPT로 바로 생성": API 설정(키·모델·품질·input_fidelity) 후 결과가 카드에 자동 삽입
- 비교 카드는 항상 1개(작업 영역). 이미지 업로드/드롭/붙여넣기/바로 올리기 → 패널(1 KEEP · 2 NATURAL · 3 GLOW) 선택 → 이름 → 데뷔. 선택 패널은 크롭 → 2× 업스케일(브라우저) 후 등록
- 내 모델·후보 그리드(blurblur 형식): 선택/데뷔 바, 데뷔됨 배지, 데뷔 취소, 삭제. 빈 카드는 맨 끝 1개만
- 썸네일 클릭 → 라이트박스(조정·데뷔 취소·삭제·N/M) → 얼굴 조정 모달(형태 7종·피부 보정·피부 디테일·밝기·따뜻함, 실시간 미리보기, 원본 해상도 적용)
- GNB Models 페이지: 데뷔 모델 목록(배지 카운트), 조정·데뷔 취소·삭제
- 얼굴 사진 삭제, 이전 셀피 개별 삭제, 전체 초기화. 상태·이미지는 localStorage에 저장(용량 초과 시 축소 저장)
- 내부용으로 제거한 것: 비용·잔액, 약관, 본인 확인 동의, IP 안내, Pricing, 변형 강도 선택(3단계 비교로 대체)

## ver2 기능 (2026-09-13 ~ 14 확정)

### 스타일링(룩) 단계
- Models → 모델 세부(`#model/<id>`) → "+ 새 룩 만들기" → `#style/<id>`. 직접 조합(프리셋·상의/색·하의/색·아우터·신발·악세서리·디렉션) 또는 의상 지정(관련 참조 이미지 ≤6장 + 디렉션; 참조 아이템은 반드시 그대로 착용, 나머지는 디렉션/자율)
- 공통 옵션: **신장**(모델에 저장, 전신 비율 문구 `heightPhrase`), **포즈**(13종, 사용자 확정 영어 매핑 `POSE_EN`; '지정 안 함'=자연스러운 정면). 포즈는 세 컷에 동일 적용, 상체 컷은 head-and-shoulders 프레임 표기
- 프레이밍 확정(`LOOK_PANELS`): **상체** 1:1 헤드샷(머리 위 여백 약 1/10, 어깨 바로 아래 윗가슴까지, 얼굴이 높이의 40~45%) · **니샷** 1:1 머리~무릎 위(허벅지 중간) · **풀샷** 2:3 머리~신발+바닥
- 프롬프트 탭: **ChatGPT 3단계**(연속 메시지 3개, 단계별 복사 버튼) / 상체 / 니샷 / 풀샷. ChatGPT는 한 메시지에 이미지를 1회만 만들므로 한 문장으로 "3장"을 요구하면 같은 크롭의 변주만 나온다 → 1단계(모델 첨부, SQUARE 1:1) → 2단계(직전 의상 그대로, 더 넓은 크롭) → 3단계(TALL PORTRAIT 2:3) 순서로 보낸다
- **GPT로 바로 생성(3장)**: 상체 → 얼굴 보정 패스(`faceFixPass`, 자동 토글) → 니샷 → 풀샷(니샷·풀샷은 상체 결과를 참조로). 결과는 룩 리스트에 직접 저장(생성 중 카드 → 완료). 룩 프롬프트의 얼굴·피부 문구는 클린 상업사진 어휘만(`FACE_DETAIL`·`LOOK_SKIN`)
- **룩 일괄 업로드**: 슬롯/"룩으로 저장" 없이, GPT에서 받은 이미지를 여러 장 한 번에 올리면 `classifyLook`(세로비 >1.15 → 풀샷, 얼굴 크기 비율 ≥0.26 → 상체, 그 외 니샷)으로 자동 분류해 바로 저장. 스타일 페이지 상단 드롭존 + 모델 세부 룩 목록 맨 끝 슬롯
- 룩 썸네일: 상체·니샷은 채움(cover), 풀샷은 잘리지 않게(contain). 모델 세부 룩 목록에 **전체/풀샷/니샷/상체 필터**(개수 표시) — 선택 프레임을 좌상단부터 먼저 배치하고 나머지는 흐리게 뒤에 모두 표시
- 스타일 페이지 맨 아래 "모델 리스트로 이동" 버튼

### Create·공통
- 후보 그리드 맨 끝에 **직접 올리기 슬롯** 고정(클릭/드롭 → 새 후보 → 이름 → 데뷔). 데뷔 카드 바는 이름(윗줄) / 데뷔 완료 · 데뷔 취소 · 삭제(아랫줄)
- 라이트박스와 모델 세부 헤더에 **다운로드**(파일명 `이름 · 데뷔.jpg`, `이름 · 룩 · 스펙.jpg`). 모델 세부 헤더는 [+ 새 룩 만들기 / 다운로드 / 데뷔 취소]만(삭제는 Models 카드·라이트박스)
- GNB 상단 고정(sticky)
- Create 패널 업스케일 언샤프 .35 → .15, 스크립트 태그 캐시 무효화 `?v=`

## ver3 기능 (2026-09-14 ~ 17 확정)

### 배경 단계 — GNB `Backgrounds` (`#bg`)
- 세그먼트 2탭: **배경 만들기 / 배경 라이브러리**. 합성은 페이지 맨 아래 **"룩에 배경 합성 — 프롬프트 만들기"** 버튼으로 펼치는 블록(탭 아님)
- **배경 만들기**: 기준 룩 선택(모델 → 룩 썸네일, 상태는 합성 블록과 공유 `S.sc`) → 스펙 키워드 규칙으로 장면 힌트 칩 4개(`recommendScenes`, 누르면 장면으로 선택) + **"ChatGPT에 자유 탐색 프롬프트 받기"**(`bgFreePrompt`): 개수·카테고리를 정하지 않고(개수 자유 / 3·5·8장 선택 가능) 크리에이티브 디렉터 역할로 룩이 살아날 장소를 자유롭게 제안하되, 장소 유형·시간대·팔레트·심도·카메라·무드가 서로 확실히 달라야 하고 비슷하면 교체하라고 지시 → 배경 플레이트(모델 없음)를 한 장씩 생성. 고정 4슬롯 개념은 폐기(결과가 비슷해지는 문제로). **🎲 랜덤 무드**: 장면·조명·심도·카메라 + 디테일 한 가지(`BG_TWIST` 16종: 젖은 바닥 반사, 컬러 젤, 블라인드 그림자…)를 무작위로 채워 단일 배경 프롬프트의 자유도를 높인다. 그 외 옵션: 장면 13종(컬러 스튜디오는 색 칩) · 조명·시간대 6종 · **심도 3종 · 카메라 3종** · 비율(1:1/2:3/3:2) · 참조 ≤3 · 디렉션 → `bgPrompt`(사람·텍스트 없음, 중앙 앞쪽 비움, 바닥 보임). GPT 바로 생성은 참조 있으면 edits, 없으면 generations. 결과는 라이브러리로
- **배경 라이브러리**: 여러 장 업로드(비율 자동 판별, 스펙 "직접 올린 배경 · 비율"), 세로/1:1/가로 필터, 카드 "이 배경으로 합성 →"(배경 선택 + 합성 블록 펼침), 삭제·라이트박스(다운로드). GNB 배지·탭 배지에 개수
- **룩에 배경 합성(블록, 브라우저 합성기)**: 프롬프트 없이 바로 확인하는 구조로 변경(2026-09-16). 모델 → 룩 → 배경(라이브러리) → 출력 비율(룩과 동일 = 상체·니샷 1:1, 풀샷 2:3 / 1:1·3:4·2:3·9:16·4:3·3:2·16:9) → 캔버스 에디터. `cutoutPerson`: 룩의 테두리 색(라이트그레이)을 기준으로 가장자리에서 연결된 유사색만 플러드필로 지워 인물을 잘라냄. 배경색은 **행별 좌·우 테두리 중앙값**으로 잡아 위아래 그라디언트를 흡수하고, 거리 = 채도 차이 ×4 + 밝기 차이 ×1(기본 허용치 12, 소프트 밴드 ×1.3). 반투명은 배경 경계 3px 안에서만 허용해 배경과 비슷한 밝은 옷 내부가 흐려지지 않게 하고, **바닥 그림자 패스**(인물 하단 22% 영역에서 배경에 연결된 저채도·어두운 픽셀 확장)로 발밑 그림자를 지운다. 이후 **섬 제거**(가장 큰 덩어리의 3% 미만·떨어진 조각 삭제) → **구멍 제거**(다리 사이·가방 틈처럼 테두리와 연결되지 않은 배경: 바깥 배경의 행별 중앙값 색과 거의 같은 색의 작은 덩어리(인물 면적 10% 미만, 평균색 거리 < 슬라이더값, 60% 이상 근접색)만 삭제 → 배경보다 밝고 큰 흰 셔츠는 보존, 슬라이더 0~30) → **엣지 다듬기(choke, 알파 최소 필터 0~4px)** → 페더 → **색 분리(decontamination, 반투명 픽셀에서 배경색 제거)**. 옷 안쪽 회색은 보존. 조정 패널은 **인물**(크기·누끼 허용치·구멍 제거·엣지 다듬기·가장자리 부드럽게·배경 톤 섞기·좌우 반전·바닥 그림자)과 **배경**(심도·채우기) 두 그룹, 각 항목은 제목·슬라이더·값 한 줄. 인물 크기는 **캔버스 높이 대비 비율**로 저장해 미리보기(긴 변 1000)와 저장(긴 변 2048)에서 같은 구도가 나온다. 인물은 드래그로 위치, 휠·슬라이더로 크기, 좌우 반전, 바닥 그림자(풀샷), 배경 톤 섞기, **배경 심도(흐림 0~30px, 캔버스 비례)**, 배경 채우기(cover/contain). 다운로드 또는 "배경 컷으로 저장"(긴 변 ≤2048, 배경 해상도에 종속) → 모델 `scenes[]`·모델 세부 "배경 컷". 예전 `scenePrompt`/API 합성 경로는 제거(프롬프트 엔진 함수는 GPT 스킬 문서 E용으로 남김)
- 라이트박스 공용 함수 `openAnyLightbox`(다운로드·삭제)

### GPT 스킬 문서 (`docs/gpt-skill/`)
- 프롬프트 엔진이 결정적(같은 옵션 → 같은 문장)이므로, 앱 없이 ChatGPT에서 **사진 + 한국어 옵션**만으로 같은 프롬프트가 나오도록 규격서를 자동 생성한다: `node tools/export-gpt-skill.js`
- `INSTRUCTIONS.md`(커스텀 GPT 지침, 짧음) + 지식 파일 `A-face-3stage`(3단계 비교·단일 단계·얼굴 옵션 사전·신장 문구) / `B-random-model` / `C-look`(ChatGPT 3단계·API 개별·의상 지정·룩 옵션·포즈 사전) / `D-background`(단일·자유 탐색·장면/조명/심도/카메라 사전) / `E-composite`(합성·출력 비율 사전) / `F-fixed-paragraphs`(POSE_LOCK·FACE_DETAIL·FACE_FIX·LOOK). `AI_model.md`는 전부 합친 판
- 코드(`js/prompt.js`)를 바꾸면 반드시 재생성. 문서를 손으로 고치지 않는다

### 저장소 (2026-09-17)
- 상태·이미지는 **IndexedDB**(`aimodel.store` / 키 `aimodel.create.v1`)에 저장한다. localStorage는 약 5MB 한도라 이미지 몇 장이면 저장이 실패해 새로고침 시 초기화되던 문제를 해결. 옛 localStorage 데이터는 첫 실행 시 자동 이전되고, IndexedDB 저장이 되면 localStorage 사본은 지운다. IndexedDB를 쓸 수 없는 브라우저(사생활 보호 모드 등)에서는 localStorage 축소 저장으로 폴백하며 안내 토스트를 띄운다.
- 저장은 브라우저·주소(origin)별이다. `localhost:8765`, GitHub Pages, 다른 PC의 데이터는 서로 보이지 않는다. 옮기려면 다운로드 → 업로드.

## ver4 (진행 중 · 2026-09-17~)

### 팀 동기화 — Supabase (`js/cloud.js`, `supabase/schema.sql`)
- 목적: 모델·룩·배경 컷·배경을 팀원과 같은 목록으로 본다. 얼굴 사진·작업 중 비교 카드·옵션은 브라우저 로컬(IndexedDB)에만.
- 준비(1회): Supabase 프로젝트 SQL Editor에서 `supabase/schema.sql` 실행 → `allowed_emails`(허용 이메일), `items`(kind: model/look/scene/bg, data jsonb, image_path/orig_path), RLS(`is_allowed()`), realtime publication, 비공개 버킷 `avatar-images`. 팀원 추가는 `insert into allowed_emails(email) values (...)`.
- 사용: 헤더 "☁ 동기화" → 설정 모달의 팀 동기화 칸에 Project URL·anon key 저장 → 이메일·비밀번호로 가입/로그인(허용 이메일만 데이터 접근). 처음 연결한 브라우저는 "이 브라우저 데이터 전부 올리기"로 기존 데이터를 업로드.
- 동작: 로컬 상태가 원본, `Cloud.sync()`가 저장(persist) 뒤 2.5초 디바운스로 실행 + realtime 변경 알림 시 재실행. 항목별 `cloudSig`(data 서명)·`cloudAt`(원격 updated_at)로 변경 감지, `S.cloudIds`(지난 동기화 id 집합)로 삭제 추적(로컬에서 사라짐→원격 삭제·파일 삭제, 원격에서 사라짐→로컬 삭제). 충돌은 로컬이 바뀌었으면 로컬 우선. 이미지는 dataURL→Blob 업로드(`kind/id.jpg`, 모델 원본은 `model/id_orig.jpg`), 내려받을 때 dataURL로 캐시.
- 설정 키: `aimodel.supabase.v1`(url, anonKey). supabase-js는 jsDelivr UMD.

## 알려진 사항

- "GPT로 바로 생성"은 일반 Chrome에서 확인 필요. Claude 데스크톱 내장 미리보기에서는 api.openai.com POST가 차단됨
- 얼굴 조정의 형태 슬라이더는 MediaPipe 모델(CDN)을 불러오며, 얼굴 미검출·오프라인이면 정면 헤드샷 비율 근사로 동작
