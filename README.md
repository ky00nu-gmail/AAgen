# AI 모델 만들기 — ver1 (2026-09-13)

blurblur `/make/model/create` 화면 구조를 그대로 옮긴 내부용 정적 웹앱. 내 얼굴 사진으로 브랜드 모델 후보를 만들고, 3단계(그대로·약하게·글로우) 비교 이미지에서 하나를 골라 데뷔한다.

## 실행

빌드 없음. `index.html`을 브라우저(Chrome 권장)로 열거나 로컬 서버로 서빙한다.

```bash
python3 -m http.server 8765
```

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면·상태·라우팅(#create / #models). 인라인 CSS/JS |
| `js/prompt.js` | GPT Image 프롬프트 엔진(순수 함수). 3단계·비교·랜덤(인간/동물/애니) 프롬프트 |
| `js/adjust.js` | 얼굴 조정(브라우저 처리): MediaPipe 랜드마크 + 국소 워프, 피부 보정/디테일, 밝기/따뜻함 |
| `js/engine.js` | OpenAI Images API 어댑터(edits / generations). 키는 localStorage |
| `tools/sample-prompts.js` | 검증용 프롬프트 매트릭스 생성 → `docs/prompt-samples.md` |
| `docs/Create AI Model — blurblur.pdf` | 원본 화면 캡처 |

## ver1 기능

- 내 얼굴 모델 / 랜덤 모델(인간·동물·애니) 탭. 얼굴 사진 업로드 → 사진 설정(원본/크롭 1:1·3:4, 드래그·줌)
- 옵션: 성별, 인종(칩) → 국가(칩), 나이대(칩), 외형 디테일(체형·헤어·컬러·눈·피부톤·메이크업·타투, 셔플), 디렉션, Tips
  - 헤어 스타일은 성별에 따라 목록이 바뀜: 여성 20종 / 남성 19종(자연스러운 숏컷·댄디컷·쉐도우펌·가르마펌·투블럭·콤마헤어·포마드 등, '지정 안 함' 포함). 프롬프트 영문 매핑은 `js/prompt.js`의 `EN.hairM`
- 생성 = 3단계 비교 프롬프트 1장(그대로·약하게·글로우, 정면 증명사진 자세, 라이트그레이 배경). 프롬프트는 버튼 아래 즉시 표시, 복사
- "GPT로 바로 생성": API 설정(키·모델·품질·input_fidelity) 후 결과가 카드에 자동 삽입
- 비교 카드는 항상 1개(작업 영역). 이미지 업로드/드롭/붙여넣기/바로 올리기 → 패널(1 KEEP · 2 NATURAL · 3 GLOW) 선택 → 이름 → 데뷔. 선택 패널은 크롭 → 2× 업스케일(브라우저) 후 등록
- 내 모델·후보 그리드(blurblur 형식): 선택/데뷔 바, 데뷔됨 배지, 데뷔 취소, 삭제. 빈 카드는 맨 끝 1개만
- 썸네일 클릭 → 라이트박스(조정·데뷔 취소·삭제·N/M) → 얼굴 조정 모달(형태 7종·피부 보정·피부 디테일·밝기·따뜻함, 실시간 미리보기, 원본 해상도 적용)
- GNB Models 페이지: 데뷔 모델 목록(배지 카운트), 조정·데뷔 취소·삭제
- 얼굴 사진 삭제, 이전 셀피 개별 삭제, 전체 초기화. 상태·이미지는 localStorage에 저장(용량 초과 시 축소 저장)
- 내부용으로 제거한 것: 비용·잔액, 약관, 본인 확인 동의, IP 안내, Pricing, 변형 강도 선택(3단계 비교로 대체)

## 알려진 사항

- "GPT로 바로 생성"은 일반 Chrome에서 확인 필요. Claude 데스크톱 내장 미리보기에서는 api.openai.com POST가 차단됨
- 얼굴 조정의 형태 슬라이더는 MediaPipe 모델(CDN)을 불러오며, 얼굴 미검출·오프라인이면 정면 헤드샷 비율 근사로 동작
